# ONEMISSION Launch Page

Temporary standalone launch countdown landing page for ONEMISSION.

## Stack

- Nuxt 3
- TypeScript
- TailwindCSS
- VueUse
- SwiperJS

No database, authentication, or backend API is required.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Static Generation

```bash
npm run generate
```

## Configuration

All launch content is managed in:

```text
launch.config.ts
```

Includes launch date, copy, SEO metadata, social links, and hero slides.
